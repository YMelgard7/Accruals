New instance checklist
1
Create a Supabase project
Go to supabase.com → New project. Free tier is enough.
2
Run the SQL
In your Supabase project → SQL Editor → New query → paste the SQL below → Run. Creates all 13 tables in one shot.
3
Update the connection in this file
In your Supabase project → Settings → API → copy Project URL and anon public key. Paste into the Connection section below and save. Or edit the two constants at the top of the <script> block directly in GitHub.
4
Deploy to GitHub Pages
Push index.html to a GitHub repo → Settings → Pages → Deploy from branch → main. Done.
